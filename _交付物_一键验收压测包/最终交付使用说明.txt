【快速开始：只需要 1 步】
═══════════════════════════════════════════════════════════════════════════

  Windows 用户（99% 情况）：
    → 双击「一键验收.bat」
    → 它会自动：
        1) 检查是否装了 Node.js（没装的话会提示安装 nodejs.org）
        2) 自动装 jsdom 依赖（只需第一次运行）
        3) 依次跑三阶段验收：
           · 阶段1：通用模板防重复注入 + JSON Perf 格式校验
           · 阶段2：核心业务分支（save/verify/audit/dispatch...）按钮回归
           · 阶段3：高并发 JSON 日志完整性压测（12页面×14按钮×4次点击）
        4) 所有控制台输出自动保存为「验收报告_YYYYMMDD_HHMMSS.log」
    → 最终输出绿色的「三阶段全部通过 ✅」或红色的硬失败定位信息

  Linux / macOS 用户：
    → 终端运行：
         chmod +x 一键验收.sh
         ./一键验收.sh
    → 功能和 Windows 版完全一致。

【我只想跑压测（单独跑高并发脚本）】
═══════════════════════════════════════════════════════════════════════════
  不跑完整三阶段，直接打开 CMD / 终端进入 _tests 目录：

  # 默认参数（12页×14按钮×4次点击，并发无限，0~15ms抖动）
  node _stress_json_integrity.js

  # ======== 常用参数组合 ========
  # 冒烟快速（30秒出结果）
  node _stress_json_integrity.js --pages 3 --clicks-per-button 1 --concurrency 3 --seed 42

  # 模拟 42 个真实用户（并发限制+真实思考时间 20~80ms）
  node _stress_json_integrity.js --pages 12 --clicks-per-button 5 \
                                 --think-min 20 --think-max 80 --concurrency 8

  # Windows CMD 设置环境变量方式（一次设置多次运行）：
  set STRESS_PAGES=12
  set STRESS_CONCURRENCY=8
  set STRESS_THINK_MIN_MS=20
  set STRESS_THINK_MAX_MS=80
  node _stress_json_integrity.js --seed 1234

  # 参数三级优先级：命令行 > 环境变量 > 默认值
  ┌─────────────┬──────────────────────┬───────────────────────┬───────────┐
  │ 配置项      │ 命令行                │ 环境变量              │ 默认值    │
  ├─────────────┼──────────────────────┼───────────────────────┼───────────┤
  │ 页面数      │ --pages N            │ STRESS_PAGES          │ 12        │
  │ 每按钮点击  │ --clicks-per-button N│ STRESS_CLICKS_PER_BTN │ 4         │
  │ 抖动最小ms  │ --think-min N        │ STRESS_THINK_MIN_MS   │ 0         │
  │ 抖动最大ms  │ --think-max N        │ STRESS_THINK_MAX_MS   │ 15        │
  │ 页面并发数  │ --concurrency N      │ STRESS_CONCURRENCY    │ 无限制    │
  │ 随机种子    │ --seed N             │ STRESS_SEED           │ 随机      │
  └─────────────┴──────────────────────┴───────────────────────┴───────────┘

【常见问题 FAQ】
═══════════════════════════════════════════════════════════════════════════

Q1: 双击 .bat 一闪而过没反应？
A1: 右键 → 用"命令提示符"打开，或在该文件夹空白处 Shift+右键 → 在此处打开 PowerShell → 输入 .\一键验收.bat

Q2: 阶段1提示"缺少 Node.js"？
A2: 打开 https://nodejs.org/ 下载 LTS 版本（Windows Installer .msi），一路下一步安装完重开 CMD 再跑即可。

Q3: 阶段3高并发压测后"accept 分支缺失"标黄色？
A3: 不影响验收通过（是 soft-only 分支，因按钮关键词"接单"与 SP 分支优先级冲突），脚本已自动标记为设计内表现，不计入硬失败。

Q4: 想把压测结果存成文件？
A4: 方式一：双击「一键验收.bat」自动保存 log；方式二：手动执行时
    node _tests\_stress_json_integrity.js --seed 123 > 压测日志_20260804.log 2>&1
