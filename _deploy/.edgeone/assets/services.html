壹乡村庙会戏曲演出

服务内容

承接各乡镇、村落传统庙会、民俗祭祀、村落庆典秦腔专场演出

场景适配

传统庙会祭祀戏 春祈秋报戏 村落开台戏 族谱庆典戏

服务流程

  • 庙会对接 → 了解庙会规格、日期、演出需求
  • 剧目确认 → 根据传统习俗和庙会主题选定剧目
  • 合同签订 → 明确双方权责、费用、演出场次
  • 排期准备 → 演员排演、舞美设备调试、行程安排
  • 现场演出 → 专业搭台、准时演出、保质保量
  • 结算归档 → 费用结算、资料留存、满意度回访

合作模式

单场包场 连台本戏（3天/5天/7天） 庙会定制套餐

合作模式

政府采购 乡镇集采 公益合作 专项文化项目

合作模式

伍天水文旅合作演出

服务内容

深度对接天水市文化和旅游局，服务于公祭伏羲大典、天水伏羲文化旅游节、南郭寺文化节、卦台山非遗节、大地湾文化宣传等全市重大文旅活动，提供专业秦腔演出与非遗展示服务。

文旅项目

公祭伏羲大典配套 伏羲文化旅游节 麦积山石窟文化周 大地湾遗址文化节 南郭寺诗圣文化节 卦台山非遗展演

专项服务

  • 伏羲文化主题剧目 — 定制伏羲祭典相关秦腔历史剧、配乐朗诵与民俗表演
  • 景区驻场演出 — 提供麦积山、伏羲庙、仙人崖等景区日常驻场演出服务
  • 文旅推介会演出 — 配合天水文旅在全国各大城市的旅游推介巡演
  • 非遗名录申报支撑 — 提供非遗申报所需演出视频、资料整理与现场演示

合作模式

文旅局专项合作 景区年度驻场 节会官方指定 文旅推介巡演

陆校园戏曲研学与非遗传承

服务内容

响应教育部"戏曲进校园"号召，为天水市大中小学、幼儿园提供专业戏曲研学课程、非遗传承体验、校园艺术节演出等一体化服务，以秦腔艺术传承西北戏曲非遗文化。

课程体系

戏曲进校园演出 秦腔唱腔兴趣班 戏曲身段体验课 戏曲化妆工作坊 非遗文化讲座 校园戏曲节编排

研学特色

  • 分级课程体系 — 幼儿园启蒙、小学兴趣、初中研学、高中社团、大学赏析五级课程
  • 配套教材教具 — 秦腔教学绘本、脸谱涂色卡、身段图卡、乐器演示教具
  • 小小传承人计划 — 选拔优秀学员组建校园小剧团，参与正式演出与赛事
  • 研学实践基地 — 开放剧团排练场、服装道具库作为研学实践教学基地

合作模式

校园年度服务 研学活动承接 课后服务课程 教育局统采项目

柒网络直播与数字演出服务

服务内容

顺应数字文化发展趋势，提供线上秦腔直播演出、虚拟排演、4K 演出录制、短视频定制、直播接口对接等数字演出服务，打破时空限制，让秦腔艺术通过互联网覆盖更多观众。

数字服务

全程多机位直播 短视频剧目剪辑 4K演出录制 直播API接口 VR全景演出 付费点播剧场

接口与交付

  • 标准 RTMP/FLV/HLS 推流 — 对接抖音、快手、视频号、B站等主流平台
  • RESTful 直播接口 — 提供订单查询、节目单下发、弹幕回调、观看统计 API 文档
  • 母带级录制交付 — 4K 多机位现场录制 + 后期精剪 + 花絮合集 + 封面海报
  • 二维码预约联动 — 直播间专属邀请二维码，扫码预约、开播提醒、回放通知

合作模式

单场直播定制 平台年度合作 付费剧场分账 接口技术对接

捌定制剧创作与专项排演

服务内容

为政府机关、企事业单位、乡镇村落、景区文旅项目提供原创秦腔剧本创作、音乐编配、导演排演、服装道具定制、首演发布一体化专项服务，打造专属文化 IP 剧目。

定制方向

村镇历史名人剧 企业精神主题剧 家风家训传承剧 文旅景区专属剧 英模人物纪实剧 时代主旋律新剧

创作交付流程

  • 题材采风 — 编剧团队实地采风、访谈调研、素材收集与历史考证
  • 剧本创作 — 大纲编写、剧本初稿、唱腔设计、专家评审、多轮修改
  • 音乐编配 — 作曲配器、乐队总谱、录音合成、主题曲目录制
  • 排演合成 — 导演排戏、身段指导、合乐彩排、服装道具舞美制作
  • 首演发布 — 组织首演仪式、媒体发布、演出视频拍摄与宣传推广

合作模式

全程委托创作 剧本单独定制 联合出品运营 年度创作服务
