1. 管理员批量补打卡功能（新功能）

后端新增 POST /v1/attendance/batch-punch 接口，权限 super_admin/ops/director。支持补卡类型（上班/下班/都补），按 (员工, 日期, 卡类型) 自动去重，状态手动指定（默认正常），单次最多 200 人，审计日志 ATTENDANCE_BATCH_PUNCH。
前端 attendance.html 新增「批量补打卡」tab，按用工类型分组显示员工，每组带全选框，支持姓名/工号搜索，提交后显示新建/跳过/失败明细。
涉及文件：server/src/controllers/attendance.js · server/src/routes/v1/index.js · admin/attendance.html · js/admin-pages/attendance.js

2. 批量补打卡 "API is not defined" 修复

前端 __bpunchNs 模块的 loadPerfs() 和 submit() 函数未获取 window.QAXQJT_API，导致「加载失败: API is not defined」。修复：函数开头加 var API = window.QAXQJT_API; + 接口未就绪保护。
涉及文件：js/admin-pages/attendance.js

3. 演职人员管理身份证号录入字段

staff.html 编辑弹窗新增「身份证号」输入框（18位 maxlength），staff.js 4 处修改：清空/启用列表、编辑回填 p.idCardNo、格式校验 ^\d{17}[\dX]$、保存传值。后端无需修改（已支持 idCardNo 字段）。
涉及文件：admin/staff.html · js/admin-pages/staff.js

4. 身份证号显示统一化

花名册详情页身份证号从脱敏显示（前4+****+后4）改为明文显示，与订单名册表格、工资协商保持一致。员工自助门户仍保持脱敏以保护隐私。
涉及文件：js/admin-pages/staff.js

5. app.js 版本号统一（116 文件）

全站 app.js 引用版本号不统一（前台 20261004b、后台 20261006c/20261007b），统一为 v=20261009a。修改 34 个源 HTML + 82 个 _deploy 副本，共 116 个文件。
涉及文件：全站 HTML 文件（116 个）

6. serve-uploads Content-Type + nosniff 安全头

上传文件中间件缺少 Content-Type 设置，图片可能被浏览器当作 application/octet-stream 下载。修复：新增 MIME_MAP（11 种扩展名映射），设置 Content-Type + X-Content-Type-Options: nosniff 防止浏览器类型嗅探。
涉及文件：server/src/middleware/serve-uploads.js

7. change-password.html 版本号参数

api-config.js 和 api-request.js 缺少 ?v= 版本号参数，可能导致更新后浏览器使用旧缓存。修复：添加 ?v=20261009a。
涉及文件：admin/change-password.html

8. .env JWT 密钥强化 + DATABASE_URL 修复

JWT 密钥从可预测默认值（qaxqjt_prod_access_secret_2026_min64chars_xyz）替换为 48 字节强随机 base64 值。部署时 DATABASE_URL 被误覆盖为 PostgreSQL URL，修复为 SQLite file:C:/qaxqjt-server/prisma/prod.db，并补充 9 个缺失环境变量。
涉及文件：server/.env
