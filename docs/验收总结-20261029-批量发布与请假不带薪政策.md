## 二、薪酬政策细则（v20261029e 生效）

**规则：任何请假或补假一律不带薪。**

| 结算模式 | 请假/补假处理 |
|---|---|
| 纯日结（daily_pure） | 当天不计工天 → 无日薪（少发而非扣款） |
| 月薪折算（daily_prorated） | 不计工天；事假桶（含补假/病假/法定假）按折算日薪 100% 扣回 |
| 按月（monthly） | 底薪全额发放 + 事假桶 × 折算日薪 100% 扣回（`enLeaveDeduct` 开关，默认开） |

**覆盖假期类型**：事假、病假、年假、婚假、丧假、工伤、公出（出差/学习/外出）、补假。
**全勤奖**：上述任一类型出现即取消全勤。
**兜底保护**：扣款合计不超过应发，实发永不为负；扣不足部分转入 `unpaidCarryOver` 下期追缴；扣款顺序为考勤罚 → 装卸车缺席 → 借款。

## 五、本轮踩坑记录（已沉淀至项目记忆）

1. **健康检查路由**：必须用 `/v1/healthz`（`/healthz` 为 404）
2. **`.env` 脏值**：服务器 `.env` 中 `LOG_LEVEL='warn '`（尾随空格）会导致 joi 拒绝 + pino 崩溃——TAT 裸跑 node 必须对环境值做 trim
3. **PS5.1 限制**：`ConvertFrom-Json` 对重复键（`username`/`USERNAME`）零容忍 → pm2 环境自举必须用 node `JSON.parse`
4. **PS 错误横幅吞行**：joi 报错明细被 NativeCommandError 红色横幅吞掉 → 用 `cmd /c "node ... 2>&1"` 捕获完整输出
5. **TAT 粘贴上限**：约 30KB，超长脚本会被截断 → 必须拆分为多个脚本
6. **假成功防护**：TAT 中 node 失败仍会打印后续输出 → 必须加 `$LASTEXITCODE` 校验后再打成功标记
7. **数据类型**：`payslipPublished` 为 SQLite 整数（1/0），严格比较需兼容

### 6.1 LOG_LEVEL 修正具体操作步骤

**背景**：`C:\qaxqjt-server\.env` 中 `LOG_LEVEL` 的值形如 `warn `（带尾随空格）。主应用（PM2）经 `server.js` 的 `dotenv.config({ override: true })` 加载时 dotenv 会自动 trim，因此**线上运行完全正常**；但任何绕过 dotenv、手工解析 `.env` 的脚本（如 TAT 里的 PowerShell 加载器或正则解析）会把 `warn ` 原样带入，导致 joi 校验拒绝 + pino 崩溃。修正它属于卫生性质的加固。

**方式一：TAT 脚本一键修正（推荐，无需登录服务器）**

将以下内容复制到腾讯云 TAT 自动化助手（PowerShell 类型，超时 60 秒）执行：

```powershell
$ErrorActionPreference='Stop'
$f='C:\qaxqjt-server\.env'
# 1) 备份
Copy-Item $f ($f + '.bak-loglevel') -Force
# 2) 仅重写 LOG_LEVEL 行为规范值（无引号、无空格），其余行原样保留
$lines=[IO.File]::ReadAllLines($f)
$new=$lines | ForEach-Object { if($_ -match '^\s*LOG_LEVEL\s*='){ 'LOG_LEVEL=warn' } else { $_ } }
# 3) UTF-8 无 BOM 写回（PS5.1 的 Set-Content -Encoding UTF8 会写 BOM，可能破坏首行解析，故用 WriteAllLines）
[IO.File]::WriteAllLines($f,$new,(New-Object Text.UTF8Encoding($false)))
# 4) 校验
$check=[IO.File]::ReadAllLines($f) | Where-Object { $_ -match '^LOG_LEVEL=' }
Write-Output ('NOW ' + $check)
if($check -cne 'LOG_LEVEL=warn'){ throw 'loglevel fix verify fail' }
Write-Output 'LOGLEVEL_FIXED'
```

**期望输出**：`NOW LOG_LEVEL=warn` + `LOGLEVEL_FIXED`

**方式二：RDP 登录手工修改**

1. RDP 连接 1.14.106.173，用记事本打开 `C:\qaxqjt-server\.env`
2. 找到 `LOG_LEVEL` 行，将值改为 `warn`（确保等号两侧与值的前后**均无空格、无引号**）
3. 保存（若记事本编码为 UTF-8 即可，无需特殊设置）
4. PowerShell 校验：`Select-String '^LOG_LEVEL=' C:\qaxqjt-server\.env`

**是否需要重启 PM2？**

- **不需要**。修正前后，经 dotenv 加载的主应用读到的都是 `warn`（dotenv 自动 trim），运行时行为无任何变化。
- 若希望保守确认，可在修正后执行 `pm2 restart qaxqjt-api`，随后 `curl http://127.0.0.1:3001/v1/healthz` 应返回 200。
- 回滚：将备份 `C:\qaxqjt-server\.env.bak-loglevel` 复制回原文件即可。
