第 二 章

标准化打包步骤

4 步规范打包 · 避免部署失败
二
标准化打包步骤（共 4 步）
  • 打开文件夹，校验资源完整性
    双击打开 qintang-troupe-system 文件夹，确认核心文件（index.html、css/style.css、js/app.js、admin目录、图片等）均存在且无缺失，确保交付包完整无损坏。
    📷 【图文占位】文件夹资源完整性校验截图（标注核心文件位置）
  • 全选 → 右键 → 压缩为 ZIP（禁止 RAR）
    按 Ctrl+A 全选文件夹内所有内容，右键选择「发送到 → 压缩(zipped)文件夹」，务必使用 ZIP 格式，严禁使用 RAR、7Z 等其他格式，EdgeOne Pages 仅支持 ZIP。
    📷 【图文占位】全选 + 右键压缩为 ZIP 操作流程图
  • 命名：秦剧团云端预约系统_最终部署包.zip
    将生成的 ZIP 压缩包重命名为统一标准名称：秦剧团云端预约系统_最终部署包.zip，便于后续识别与归档管理。
    📷 【图文占位】压缩包标准命名示例图
  • 压缩包校验：大小正常 + 无嵌套文件夹
    双击打开 ZIP 进行校验：① 确认文件大小正常（通常 2-20MB）；② 核心！打开 ZIP 后直接看到 index.html 等核心文件，禁止出现多一层嵌套文件夹（例：ZIP → qintang-troupe-system → index.html 为错误结构，正确应为 ZIP → index.html）。
    📷 【图文占位】正确（无嵌套） vs 错误（多层嵌套）对比图
⚠️
核心警告！压缩格式与嵌套结构
① 禁止使用 RAR 格式：EdgeOne Pages 仅识别 ZIP，RAR 上传会直接报错导致部署失败；
② 禁止多层嵌套文件夹：若 ZIP 内多套了一层文件夹，部署后会全站 404 找不到文件，务必确保核心文件在 ZIP 根目录！

平台上传部署步骤

5 步零配置 · 自动上线
三
平台上传部署步骤（共 5 步）
  • 腾讯云 → EdgeOne Pages 控制台
    登录腾讯云官网，搜索「EdgeOne」进入产品控制台，在左侧菜单找到「Pages 静态网站托管」模块，点击进入项目管理主界面。
    📷 【图文占位】EdgeOne Pages 控制台入口定位截图
  • 创建项目 → 选择「从本地 ZIP 包部署」
    点击「新建项目」按钮，在部署方式选项中选择 「从本地 ZIP 包部署」（不要选 Git 仓库、不要选框架预设），填写项目名称（如：qintang-troupe），项目描述可留空。
    📷 【图文占位】新建项目 + 选择 ZIP 部署方式界面
  • 上传 ZIP → 等待平台解析
    点击「选择文件」上传打包好的 秦剧团云端预约系统_最终部署包.zip，等待 10-30 秒平台自动解析文件结构，确认解析后显示的根目录文件清单中 index.html 存在且在第一层。
    📷 【图文占位】ZIP 上传进度条 + 解析成功文件清单
  • 所有配置保持默认（无需修改，零配置）
    编译命令、输出目录、环境变量、框架选择、自定义域名等所有选项全部默认留空，本系统已做 EdgeOne 专属零配置适配，改任何一项都可能导致部署异常，切记不要做任何修改！
    📷 【图文占位】配置项默认值展示图（红框标注「全部保持默认」）
  • 点击【确认部署】→ 自动编译 + CDN 分发 + 公网上线
    点击「确认部署」按钮，平台将自动完成：文件解压 → 资源校验 → 编译托管 → CDN 全网分发 → 生成公网访问域名，整个过程约 1-3 分钟，请耐心等待进度条完成。
    📷 【图文占位】部署进度 + 部署成功 + 公网域名展示图

部署注意事项

4 条红色警示 · 规避部署失败
六
部署注意事项（4 条红色警示框）
❌
禁止修改原生 JS / 删除年份脚本
严禁手动修改 js/year-lite.js、js/app.js 核心脚本，严禁删除年份动态渲染相关代码；任何改动都会导致预约表单失效、{year} 渲染残留、阶梯优惠计算异常，直接影响系统核心功能。
❌
禁止 RAR 格式 / 多层嵌套
严禁使用 RAR、7Z 等非 ZIP 压缩格式（EdgeOne 不识别直接报错）；严禁 ZIP 内嵌套多层文件夹（部署后全站 404）。压缩格式 + 根目录结构两条为最高优先级红线，违者直接部署失败。
❌
禁止随意更改平台默认配置
EdgeOne Pages 的编译命令、输出目录、框架预设、环境变量、路由规则、缓存策略等全部保持默认值，任何一项随意改动均可能导致 CDN 失效、页面打不开、资源加载失败，务必零配置部署。
✅
系统全自动跨年迭代 · 永久免维护免改码
本系统内置 year-lite.js 全自动年份动态脚本，每年 1 月 1 日零点自动全站更新为新年份，无需人工改任何代码、无需重新部署、无需登录后台，一次部署永久跨年免维护，彻底告别年底改年份烦恼。
💡 小贴士：部署异常快速排查清单
① 部署失败 404 → 检查 ZIP 是否嵌套文件夹    ② 白屏样式错乱 → 检查是否误改了平台配置    ③ 年份没渲染 → 检查 js/year-lite.js 是否存在 / 是否被删除    ④ 加载慢卡顿 → 检查 CDN 缓存是否启用（默认启用即可）

七
项目部署预览规范（上线前校验标准 · 重要！）
7.1 预览触发方式
ZIP 包上传至 EdgeOne Pages 后，平台在正式部署前会自动生成临时预览域名；在部署详情页点击【预览访问】按钮，即可打开离线预览环境进行上线前的完整校验。预览环境与最终正式公网环境代码、资源、配置100% 完全一致，预览合格即等同于正式上线合格，可放心发布。
📷 【图文占位】EdgeOne Pages 部署详情页「预览访问」按钮位置 + 临时预览域名示意图
7.2 预览必查 5 核心项（逐项打勾确认）
  • 页面完整性（7 前台 + 无 404）
    首页 / 剧团简介 / 剧目中心 / 演出业务 / 新闻动态 / 在线预约 / 联系我们共 7 个前台页面 + 后台管理入口全部可正常打开，无 404 死链。
  • 动态渲染（{year} 无残留 + 脚本零报错）
    全站页面检查：页脚版权、标题中的 {year} 全部渲染为实际年份（{year}）；浏览器控制台 Console 面板零红色 JS 报错。
  • 多终端适配（PC / 手机视图切换）
    浏览器切换「响应式模式」或使用手机扫码访问，PC、平板、手机三种视口下页面均自适应，无横向滚动、无排版错乱。
  • 功能可用性（预约表单 / 优惠展示 / 跳转）
    预约表单可填写提交、场次输入阶梯优惠联动准确、导航跳转流畅、剧目卡片加载完整、后台登录页正常打开。
  • 资源加载（CDN 预加载 + 无卡顿无白屏）
    首屏加载 ≤ 2 秒、刷新无白屏、图片无裂图、CSS/JS 资源全部 200 状态码命中 CDN、页面滚动流畅无卡顿掉帧。

8.2 异常处理规范

出现异常立即执行以下流程：
① 终止发布 → 预览环境发现任意瑕疵，立即取消部署，绝不可带病上线；
② 核对资源 → 回到本地对照「第四章 · 部署校验 5 条标准」逐项排查，确认是打包问题、文件缺失、还是脚本异常；
③ 修复问题 → 针对问题根因修复（例如：嵌套文件夹 → 重新打包；脚本缺失 → 恢复 js 文件；配置误改 → 恢复默认配置）；
④ 重新打包 → 修复完成后严格按照「第二章 · 标准化打包 4 步」重新生成合规 ZIP；
⑤ 重新预览 → 上传新 ZIP、生成新预览环境、重复 7.2 节 5 项必查核心清单；
⑥ 合格上线 → 预览终审全部通过，点击【确认发布】正式公网上线。
