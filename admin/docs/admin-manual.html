一、账号登录 & 模式切换

1.1 首次登录（本地验收 / 演示模式）

  1. 打开登录页 → 默认显示绿色「🟢 生产模式（安全）」状态条（安全加固 A-1 默认启用，零演示账号）
  2. 如果您是本地验收：
  • 按 F12 打开控制台（Console）
  • 执行以下命令切到演示模式 → 页面自动刷新

```javascript

localStorage.setItem("qaxqjt_deploy_mode","demo")

```

  1. 刷新后显示黄色「🟡 演示模式（仅本地测试）」状态条 + 演示账号密码框
  2. 演示密码每小时自动变更（例：2026 年 8 月 3 日 15 点 → Qaxqjt@2026080315!），登录框里显示的就是当小时密码，直接复制粘贴
  3. 三岗演示账号同密码：
角色用户名权限
🔴 超级管理员admin全权限（财务结账/系统备份/账号管理）
🟡 财务岗caiwu财务+考勤工资+报表，无账号管理/系统备份
🟢 员工岗yuangong考勤查询+花名册+档期，无财务/无写操作

1.2 切回生产模式（正式上线前必做）

// F12 Console 执行 → 刷新：
localStorage.removeItem("qaxqjt_deploy_mode")

切回后所有本地演示账号禁用，登录必须走后端鉴权（见《E-2 后端 REST 鉴权规范 v1.0》）。

1.3 找回用户名 / 密码

登录页下方两个链接：

  • 🤔 找回用户名：输入注册手机号 + 短信验证码 6 位 → 返回用户名
  • 🔑 找回密码：输入手机号 + 短信验证码 → 设置新密码（≥8位，含大小写字母数字符号）

💡 首次上线无后端时，找回密码走本地演示流程：点击找回密码 → 输入演示手机号 13909380001 → 演示验证码固定 888888 → 设置新密码

1.4 安全规范（必须遵守）

  • ⚠️ 公共/共享电脑：绝对不勾选「记住用户名」，使用完点右上角「退出登录」
  • ⚠️ 连续输错密码 5 次：图片验证码强制出现；连续 10 次 → 账号锁定 30 分钟
  • ⚠️ 财务岗每 90 天强制改密（后端对接后生效；前端已有 UI 入口）

三、订单预约与客户管理（orders.html · 3 Tab）

3.1 Tab 1：预约申请审核（booking.html 前台自助填写 → 后台审核）

列表字段：申请时间 / 客户姓名 / 手机号 / 单位 / 连演场数 / 期望首演 / 剧目 / 地点 / 状态 → 操作列

状态说明操作
pending 待审核（默认）新订单 24 小时内必须审核「查看详情 → 通过 / 拒绝」
approved 已通过 → 自动生成正式订单弹出转订单对话框：合同总额 / 收款计划 / 节目单✅ 转订单成功写 orders + customers + schedules
rejected 拒绝必须填拒绝原因（例：档期已排满）拒绝原因自动发客户短信（后端对接后生效）

操作流程：

1. 点「查看详情」→ 右侧抽屉展开
2. 核对 5 项：客户实名、手机号、地点可达、剧目我们有、连演场数可行
3. 通过 → 弹出转订单：
   ① 合同总额 = 单场报价 × 场数 + 运输差旅 ± 其他
   ② 收款计划：定金 30%（合同签） + 中期 40%（首演前 3 天） + 尾款 30%（末演次日）
   ③ 节目单按天选剧目（每天 1 本戏 + 1 折子戏）
4. 确认 → Toast「订单已创建：QX-20260803-001」

3.2 Tab 2：正式演出订单（财务核心）

  • 🎭 绑定阵容卡：选 cast_sheets_v1 某场阵容（A4 打印单场阵容用）

7.1 流程总览（标准月末结算）

1 日-月末 每日打卡（3 种方式：海康门禁ISAPI自动同步 / 手工CSV导入 / 单条录入）
       ↓
每日下班前核对考勤（考勤岗 yuangong 可看，caiwu 可改）
       ↓
当月 25 日 工资预结算（草稿态），全团复核 3 天
       ↓

       ↓
次月 1 日 上月数据锁定（只能查不能改，改需特殊权限+审计留痕）

7.2 Tab 1：打卡 & 日考勤

3 种打卡录入方式（选 1 种，不混用）：

方式适用场景操作步骤
① 海康/腾讯 ISAPI 门禁自动同步（推荐 ≥ 30 人团）剧团门口装门禁，员工刷卡/人脸右上角「门禁配置」→ 填门禁 IP / 账号密码 / 时间段 → 点「立即同步（最近 3 天）」 → 自动写 att_clocks_v2 + ISAPI 状态
② 上传考勤 CSV（中型团，旧系统平移）用 Excel 记考勤 → 另存 CSV① 点「📥 下载示例 CSV」→ 填完保存 → ② 点「📤 上传考勤 CSV」→ 自动匹配员工姓名（模糊匹配）→ 预览 50 行 → 确认导入
③ 单条/批量人工补录（小团/临时用）10 人以下团或当天忘刷卡点「✍️ 人工补录」→ 选员工 + 日期 → 选类型（正常/迟到/早退/旷工/事假/病假/装台/卸台）→ 分钟数填对 → 提交

日类型标记（民营剧团必备）：

  • 选中某天某些员工 → 右键「批量设为：装台 / 卸台 / 常规」
  • 装台 / 卸台：按 × 1.0 工次算（如需 × 1.5 工资，在 wage_rules_v1 里配系数）

表现奖励 & 演出事故登记：

  • 点某员工某天行 → ➕「🏆 当日突出奖励（50/100/200 自定义）」
  • 点某员工某天行 → ➕「⚠️ 演出事故（L1一般50 / L2较重200 / L3严重500元）→ 填描述 + 证据照片」
  • 所有登记自动进入 att_audit_v2 审计日志（永不删除，财务可追溯）

7.3 Tab 2：月度工资结算（核心 🔴）

步骤：
1. 选结算月份（例 2026-08） → 点「🔄 开始核算」
2. 系统自动算：
   应发 = 日工资基数×工次 + 夜场补贴×15/场 + 特殊奖励 - 迟到扣款(按规则阶梯) - 旷工罚款(双倍日薪) - 事故罚款 + 全勤奖(命中规则得300否则0) - 社保个人
   个税 = 按年累计预扣（5000 起征，7 级税率）
   实发 = 应发 - 个税
3. 生成草稿态工资条列表：
   每行 = 一个员工 + 明细列（基础/夜场/奖励/扣款/社保/个税/实发）全部可见
4. 全团复核：
   员工自己 → 员工端小程序/HTML（可选功能）查询确认
   财务岗 caiwu → 核对每个异常（迟到扣款、事故罚款）附件
5. 财务点「✅ 批准工资表」
6. 财务点「💰 推送财务（生成支出凭证）」→ 自动 fin_ledger_v1 写一条工资支出（批量：所有员工合一张凭证，明细在 remark 列出）
   → 财务那边会看到对应凭证号，和银行流水对账
7. 点「🖨 批量打印 A5 工资密封条」→ 每人一页 A5，折三折后密封条封口

全勤奖命中规则（系统硬规则）：

✅ 得 300 元 条件（同时满足）：
① 当月无旷工
② 当月无事假
③ 当月迟到 ≤ 2 次 且 每次迟到 ≤ 15 分钟
④ 病假 ≤ 1 天（凭医院证明）
有任一不满足 → 全勤奖 = 0 元

7.4 Tab 3：工资规则配置（档位/日薪/扣款阶梯）

  • 新建规则：名称（如「A+ 演员 8 月旺季」）+ 5 类选择 + 档位 A+ + 基本日工资 260 元 + 档位系数 1.3
  • 迟到阶梯：0-15min 0 元（口头警告），16-30min 30 元，31-60min 50 元，>60min 当日半薪
  • 旷工：扣双倍日工资 + 取消当月全勤
  • 事故等级：L1=50 / L2=200 / L3=500

7.5 Tab 4：ISAPI 门禁对接状态

  • 最后同步时间 / 累计摄取打卡 1287 条 / 最后同步范围
  • 「排查工具」：门禁 IP 联通性测试 / 摄像头实时画面 / 未匹配名单（刷了卡但系统里没有这个员工的 → 手动绑定）

7.6 Tab 5：审计日志

15.3 投放图片（两种方式，任选其一）

方式 A：本地上传（推荐，普通管理员首选）

  1. 在目标卡片点 ⬆ 上传图片 → 弹出系统选图窗口
  2. 选择本地图片（仅图片文件，单张 不超过 10MB）
  3. 系统自动上传 → 自动把图片地址填入输入框 → 自动保存
  4. 看到绿色提示「✅ 投放成功，前台刷新即生效」即完成，卡片状态变为「已投放」并显示预览

方式 B：粘贴外链 URL（已有图床/公众号素材链接时）

  1. 把图片链接粘贴到卡片的 URL 输入框
  2. 点 💾 保存
  3. 链接必须是以下格式，否则会被拦截：
  • https://... 或 http://... 开头的完整网址
  • /uploads/... 等站内路径
  • data:image/... Base64 内联图（一般无需手填）
  1. ⚠️ 外链注意事项：
  • 微信公众号素材（mmbiz.qpic.cn 等）多带有防盗链，可能在前台显示红叉，建议改用方式 A 直接上传
  • 官网为 HTTPS 访问，粘贴 http:// 图片可能被浏览器拦截（混合内容），优先用 https:// 链接或直接上传

15.4 恢复默认图（撤销投放）

  1. 在目标卡片点 ↩ 恢复默认
  2. 弹窗确认：「确定恢复〈点位 key〉为页面默认图吗？已投放的图片将不再显示。」
  3. 点确定 → 该点位重新显示页面出厂内置图片，状态徽标变回「默认图」
  4. 恢复默认只解除投放关系，不删除服务器上已上传的图片文件本身

15.5 前台生效时间与核对方法

  • 新访客（未打开过网站的浏览器）：保存后立即生效
  • 老访客：浏览器对投放清单有最长 5 分钟本地缓存；超过 5 分钟自动刷新。如需立刻看到，在前台页面按 Ctrl + F5（Mac：Cmd + Shift + R）强制刷新即可
  • 后台保存动作会自动清除当前管理浏览器的缓存，因此点页面右上「👁 预览官网」打开的页面一定是最新的
  • favicon 特殊情况：浏览器对标签页图标缓存非常顽固，强制刷新后仍不更新时，关闭该标签页重新打开，或重启浏览器即可
  • 系统在接口故障时会自动回退默认图，不会因投放功能导致前台裂图

1登录提示「🔐 生产模式：请先配置后端鉴权地址」默认生产模式，未切 demo / 未接后端① 本地验收：F12 执行 localStorage.setItem("qaxqjt_deploy_mode","demo") 刷新
② 生产：按 E-2 文档配置 __BACKEND_AUTH_URL
2切到「⏳ 未收欠款」显示空白橙色面板？不是 Bug，是所有订单都结清了面板上有「📋 去订单预约管理」新增订单 → 故意不付清 → 回来就看到列表了
3未收欠款 Tab 连续滚十几屏不到底旧版本 Bug，8.3 版已修请升级到 V2026.8.3 最终版 ZIP，现在 scrollHeight / clientHeight = 3.74，≤ 4 屏
4上传考勤 CSV 提示「未找到姓名列」CSV 列名没写「姓名」或写成了「名字/员工姓名」下载示例 CSV，严格按示例列名填（模糊匹配支持：员工名、员工姓名、Name）
5员工迟到 20 分钟但系统没扣款？wage_rules_v1 规则里 0-15=0，16-30=30，20 分钟应该扣 30 元，请检查：① 该员工对应的 wage_rule 是否正确绑定；② 考勤类型是否真的是"迟到"（不是"事假"）
6财务「推送工资」后 fin_ledger 里没看到凭证？检查 3 项：① 当前用户是不是 admin/caiwu 有权限？② 工资表是不是已经批准了（draft 不能推）？③ 当月是不是已关账（关账后禁止新凭证）？
7库存盘点差异 1.2% 不让通过？默认容差 1% 自动通过，>1% 必须走 admin 财务总监复审 → system.html 给账号加「inventory:stocktake_override」权限 → 再点通过
8cast-sheet 打印 A4 阵容卡时空白？PDF 生成前未选要打印的场次 → 顶部多场管理 Tab → 勾 2-3 场前面的勾选框 → 再点「🖨 勾选打印」
9民营组团套用模板后 36 人没填满？模板定义默认人数 36，但实际模板里某行当选了"可缺人 1-2 名" → 正常现象，补齐需要的人即可，不会预算报错
10手机微信里上传 PDF/扫描件失败？微信 X5 内核偶发 FormData 文件 > 8MB 拦截① 图片先压缩（微信拍照 2-3MB 可过）
② 换手机浏览器 Edge/Chrome 独立打开
③ 后端对接后调整 maxUploadSize = 20MB
11忘记密码 + 短信也收不到？联系 admin 超级管理员 → accounts.html → 找到对应账号 → 点「重置密码」→ 系统生成 12 位新密码 + 强制 7 天内改密
12月末关账后发现 1 张凭证错了？关账后不能改原凭证 → 走「红冲」流程：fin_ledger 里作废原凭证 + 新增一张正确凭证 + 备注写清楚「红冲 202608XX 号凭证，原因：XXX」+ 财务审核人签字
13备份 ZIP 下载失败（显示「超出 localStorage 配额」）浏览器 localStorage 通常 5-10MB，数据超量① 清理旧备份：backups_v2 删 90 天前备份 + 清浏览器缓存
② 后端对接后备份直接存 COS，不走 localStorage
14浏览器刷新/换电脑后登录态消失？正常安全机制：Session 2 小时 TTL，跨电脑必须重新登录勾选「记住用户名」≠ 记住登录态，仅记住用户名，密码仍需输
15图片投放保存成功，前台却没变化？老访客浏览器有最长 5 分钟投放清单缓存；favicon 缓存更久① 前台按 Ctrl+F5 强制刷新；② 等 5 分钟再看；③ favicon 需关闭标签页重开或重启浏览器；④ 仍异常点后台「🔄 刷新」确认卡片是「已投放」状态（详见 15.5）
16投放后前台图片位置出现红叉/裂图？外链图片防盗链或 HTTPS 混合内容拦截不用外链，改在卡片点「⬆ 上传图片」直接上传本地图片；图片本身须 ≤10MB
17替换二维码后扫码打不开？二维码图片不清晰/留白不足，或链接本身失效用 400×400px 以上正方形 PNG，四周留白；保存后立即用手机微信/支付宝实测扫码，异常即点「↩ 恢复默认」换回
