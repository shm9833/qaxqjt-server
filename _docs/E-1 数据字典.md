# 秦安县秦剧团云端预约系统 · 数据字典 v1.0

> **文档版本**：v1.0 · 2026-08-03  
> **适用版本**：qaxqjt V2026.8.3  
> **存储后端**：浏览器 `localStorage`（纯前端演示模式）/ 后端 REST（生产模式）  
> **键名前缀**：`qaxqjt_`（由 `Storage.PREFIX` 统一拼接，以下 KEY 名均省略前缀）

---

## 0. 约定与命名规范

| 规范 | 说明 |
|---|---|
| 主键 ID | `{3-6 字母缩写}_{12 位 36 进制随机}`，例：`apt_bx92ks8zm1qp` / `fin_ledger_L3kZpQa7mN` |
| 时间戳字段 | 双写：`createdAt` / `updatedAt` 存 ISO 8601 字符串；`_ts`（部分表）存 Unix ms，用于排序 |
| 软删除 | 业务表统一 `status: 'deleted'` 标识，不物理删除（财务类禁止任何删除） |
| 操作人审计 | 业务操作字段：`operatorId` / `operatorName` / `_ts` 三件套 |
| 导出格式 | CSV / JSON 双格式，字段名严格与本表保持一致 |

## 一、鉴权 & 系统辅助表（6 张）

### 1. `admin_session`（管理员登录会话）
- 写入点：login.html → `loginUser()`
- 校验点：12 页 admin/*.html 顶部 `Admin.checkAuth()`
- **TTL：2 小时**，登出后加入黑名单防复用

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | ✅ | `sess_` + 32 hex（crypto.getRandomValues） |
| username | string | ✅ | 登录账号（如 `admin`） |
| name | string | ✅ | 显示名（如「系统管理员」） |
| role | enum | ✅ | `admin` / `finance` / `staff` |
| roleName | string | ✅ | 角色中文名 |
| loginAt | ISO string | ✅ | 登录时间 |
| expiresAt | number(ms) | ✅ | `loginAt + 2*3600*1000`，过期强制下线 |

## 十、版本迁移脚本（启动顺序）

1. `app.js` 启动时执行 `Storage.migrateV1toV2()`（一次性，幂等）
2. 迁移顺序：
   ① 旧 admin session → 黑名单清理
   ② `finance` → `fin_ledger_v1` + `fin_payments_v1`
   ③ `inventory` → `equipment_items_v1` + `borrow_logs_v1`
   ④ `performers` → `performers_db_v1`
   ⑤ `attendance_*` → attendance_v1 + wags_v1
3. 迁移前后做 SHA-256 备份快照（写 `backups_v2` 一条"迁移前备份"）
4. 任意迁移失败 → 回滚（恢复备份）+ Toast「请联系技术支持」，**绝不允许半迁移**
