## 一、账号登录 & 模式切换

### 1.1 首次登录（本地验收 / 演示模式）

1. 打开登录页 → 默认显示**绿色「🟢 生产模式（安全）」**状态条（安全加固 A-1 默认启用，零演示账号）
2. 如果您是本地验收：
   - 按 `F12` 打开控制台（Console）
   - 执行以下命令切到演示模式 → 页面自动刷新
   ```javascript
   localStorage.setItem("qaxqjt_deploy_mode","demo")
   ```
3. 刷新后显示**黄色「🟡 演示模式（仅本地测试）」**状态条 + 演示账号密码框
4. **演示密码每小时自动变更**（例：2026 年 8 月 3 日 15 点 → `Qaxqjt@2026080315!`），登录框里显示的就是当小时密码，直接复制粘贴
5. 三岗演示账号同密码：
   | 角色 | 用户名 | 权限 |
   |---|---|---|
   | 🔴 超级管理员 | `admin` | 全权限（财务结账/系统备份/账号管理） |
   | 🟡 财务岗 | `caiwu` | 财务+考勤工资+报表，**无账号管理/系统备份** |
   | 🟢 员工岗 | `yuangong` | 考勤查询+花名册+档期，**无财务/无写操作** |

### 1.2 切回生产模式（正式上线前必做）

```javascript
// F12 Console 执行 → 刷新：
localStorage.removeItem("qaxqjt_deploy_mode")
```

切回后所有本地演示账号禁用，登录必须走后端鉴权（见《E-2 后端 REST 鉴权规范 v1.0》）。

### 1.3 找回用户名 / 密码

登录页下方两个链接：
- 🤔 **找回用户名**：输入注册手机号 + 短信验证码 6 位 → 返回用户名
- 🔑 **找回密码**：输入手机号 + 短信验证码 → 设置新密码（≥8位，含大小写字母数字符号）

> 💡 首次上线无后端时，找回密码走本地演示流程：点击找回密码 → 输入演示手机号 `13909380001` → 演示验证码固定 `888888` → 设置新密码

### 1.4 安全规范（必须遵守）

- ⚠️ **公共/共享电脑**：绝对不勾选「记住用户名」，使用完点右上角「退出登录」
- ⚠️ **连续输错密码 5 次**：图片验证码强制出现；连续 10 次 → 账号锁定 30 分钟
- ⚠️ **财务岗每 90 天强制改密**（后端对接后生效；前端已有 UI 入口）

### 2.1 6 张核心卡

| 卡片 | 说明 | 点击跳转 |
|---|---|---|
| 本月营业额（元） | 当月所有演出订单合同总额合计 | → 订单预约管理 |

| 库存预警数 | inv_alerts_v1 未处理条数 | → 道具服装库存 |
| 本月考勤异常数 | attendance_v1 迟到/早退/旷工/事故 合计 | → 考勤与薪酬管理 |

### 2.2 5 张图表

1. **营业额趋势（最近 12 个月柱状图）**：月度总营业额，点击柱子跳当月订单
2. **剧目热度排行（前 10 饼图）**：按演出场数排序，冷门剧目考虑排期优化

### 2.3 右侧预警卡（实时刷新）

- 🔴 **严重**：未收欠款 ≥ 30 天、演出当日无阵容（cast_sheet 空）、库存低于安全线 × 3 项
- 🟡 **警告**：7 天内有保养到期设备、员工请假未审批
- 🟢 **常规**：明日演出提醒、未读工单（资质/合作对接）

## 三、订单预约与客户管理（orders.html · 3 Tab）

### 3.1 Tab 1：预约申请审核（booking.html 前台自助填写 → 后台审核）

列表字段：申请时间 / 客户姓名 / 手机号 / 单位 / 连演场数 / 期望首演 / 剧目 / 地点 / 状态 → 操作列

| 状态 | 说明 | 操作 |
|---|---|---|
| `pending` 待审核（默认） | 新订单 24 小时内必须审核 | 「查看详情 → 通过 / 拒绝」 |
| `approved` 已通过 → 自动生成正式订单 | 弹出**转订单对话框**：合同总额 / 收款计划 / 节目单 | ✅ 转订单成功写 orders + customers + schedules |
| `rejected` 拒绝 | 必须填拒绝原因（例：档期已排满） | 拒绝原因自动发客户短信（后端对接后生效） |

**操作流程：**
```
1. 点「查看详情」→ 右侧抽屉展开
2. 核对 5 项：客户实名、手机号、地点可达、剧目我们有、连演场数可行
3. 通过 → 弹出转订单：
   ① 合同总额 = 单场报价 × 场数 + 运输差旅 ± 其他
   ② 收款计划：定金 30%（合同签） + 中期 40%（首演前 3 天） + 尾款 30%（末演次日）
   ③ 节目单按天选剧目（每天 1 本戏 + 1 折子戏）
4. 确认 → Toast「订单已创建：QX-20260803-001」
```

### 3.2 Tab 2：正式演出订单（财务核心）

顶部搜索：订单号 / 客户姓名 / 剧目 / 日期范围 / 收款状态 → 查询 + 导出 Excel

每行操作：
- 📄 **打印合同**：A4 横版，自动套剧团抬头 + 合同双方签名栏
- 💰 **登记收款**（未收欠款 >0 时才可用）：弹出登记单 → 写入 fin_payments_v1 + fin_ledger_v1（两张表双写，不可拆分）
- 👥 **派工**：弹出「民营剧团组团」对话框，套用 troupe_templates_v1 + 当次议价
- 🎭 **绑定阵容卡**：选 cast_sheets_v1 某场阵容（A4 打印单场阵容用）
- ✅ **完结**：收款全清 + 演出全结束 → 状态变 `paid` 已结清

### 3.3 Tab 3：客户档案库（CRM）

- 预约转正时自动同步：按手机号去重，同一客户重复下单自动聚合
- 手动新增/编辑客户：客户姓名 / 手机号 / 单位 / 地址 / 标签（老客户/重点村/赖账客户）/ 备注
- 顶部「客户画像」按钮：选中 1 个客户 → 弹窗显示 5 项：
  ① 历史订单数 ② 累计交易额 ③ 当前未收余额 ④ 演出偏好剧目 ⑤ 付款及时性评分（定金准时率）

## 七、考勤与薪酬管理（attendance.html · 5 Tab）

### 7.1 流程总览（标准月末结算）
```
1 日-月末 每日打卡（3 种方式：海康门禁ISAPI自动同步 / 手工CSV导入 / 单条录入）
       ↓
每日下班前核对考勤（考勤岗 yuangong 可看，caiwu 可改）
       ↓
当月 25 日 工资预结算（草稿态），全团复核 3 天
       ↓
当月 28 日 admin 最终批准 → 推送财务 → 工资条打印 → 发工资
       ↓
次月 1 日 上月数据锁定（只能查不能改，改需特殊权限+审计留痕）
```

### 7.2 Tab 1：打卡 & 日考勤

**3 种打卡录入方式（选 1 种，不混用）：**

| 方式 | 适用场景 | 操作步骤 |
|---|---|---|
| **① 海康/腾讯 ISAPI 门禁自动同步（推荐 ≥ 30 人团）** | 剧团门口装门禁，员工刷卡/人脸 | 右上角「门禁配置」→ 填门禁 IP / 账号密码 / 时间段 → 点「立即同步（最近 3 天）」 → 自动写 att_clocks_v2 + ISAPI 状态 |
| **② 上传考勤 CSV（中型团，旧系统平移）** | 用 Excel 记考勤 → 另存 CSV | ① 点「📥 下载示例 CSV」→ 填完保存 → ② 点「📤 上传考勤 CSV」→ 自动匹配员工姓名（模糊匹配）→ 预览 50 行 → 确认导入 |
| **③ 单条/批量人工补录（小团/临时用）** | 10 人以下团或当天忘刷卡 | 点「✍️ 人工补录」→ 选员工 + 日期 → 选类型（正常/迟到/早退/旷工/事假/病假/装台/卸台）→ 分钟数填对 → 提交 |

**日类型标记（民营剧团必备）：**
- 选中某天某些员工 → 右键「批量设为：装台 / 卸台 / 常规」
- 装台 / 卸台：按 × 1.0 工次算（如需 × 1.5 工资，在 wage_rules_v1 里配系数）

**表现奖励 & 演出事故登记：**
- 点某员工某天行 → ➕「🏆 当日突出奖励（50/100/200 自定义）」
- 点某员工某天行 → ➕「⚠️ 演出事故（L1一般50 / L2较重200 / L3严重500元）→ 填描述 + 证据照片」
- **所有登记自动进入 att_audit_v2 审计日志（永不删除，财务可追溯）**

### 7.3 Tab 2：月度工资结算（核心 🔴）

```
步骤：
1. 选结算月份（例 2026-08） → 点「🔄 开始核算」
2. 系统自动算：
   应发 = 日工资基数×工次 + 夜场补贴×15/场 + 特殊奖励 - 迟到扣款(按规则阶梯) - 旷工罚款(双倍日薪) - 事故罚款 + 全勤奖(命中规则得300否则0) - 社保个人
   个税 = 按年累计预扣（5000 起征，7 级税率）
   实发 = 应发 - 个税
3. 生成草稿态工资条列表：
   每行 = 一个员工 + 明细列（基础/夜场/奖励/扣款/社保/个税/实发）全部可见
4. 全团复核：
   员工自己 → 员工端小程序/HTML（可选功能）查询确认
   财务岗 caiwu → 核对每个异常（迟到扣款、事故罚款）附件
5. 财务点「✅ 批准工资表」
6. 财务点「💰 推送财务（生成支出凭证）」→ 自动 fin_ledger_v1 写一条工资支出（批量：所有员工合一张凭证，明细在 remark 列出）
   → 财务那边会看到对应凭证号，和银行流水对账
7. 点「🖨 批量打印 A5 工资密封条」→ 每人一页 A5，折三折后密封条封口
```

**全勤奖命中规则（系统硬规则）：**
```
✅ 得 300 元 条件（同时满足）：
① 当月无旷工
② 当月无事假
③ 当月迟到 ≤ 2 次 且 每次迟到 ≤ 15 分钟
④ 病假 ≤ 1 天（凭医院证明）
有任一不满足 → 全勤奖 = 0 元
```

### 7.4 Tab 3：工资规则配置（档位/日薪/扣款阶梯）
- 新建规则：名称（如「A+ 演员 8 月旺季」）+ 5 类选择 + 档位 A+ + 基本日工资 260 元 + 档位系数 1.3
- 迟到阶梯：0-15min 0 元（口头警告），16-30min 30 元，31-60min 50 元，>60min 当日半薪
- 旷工：扣双倍日工资 + 取消当月全勤
- 事故等级：L1=50 / L2=200 / L3=500

### 7.5 Tab 4：ISAPI 门禁对接状态
- 最后同步时间 / 累计摄取打卡 1287 条 / 最后同步范围
- 「排查工具」：门禁 IP 联通性测试 / 摄像头实时画面 / 未匹配名单（刷了卡但系统里没有这个员工的 → 手动绑定）

### 7.6 Tab 5：审计日志
- 所有人工修改操作：谁、何时、改了谁、原值→新值
- 过滤器：操作人 / 操作类型 / 日期范围 / 涉及员工
- 导出 Excel（合规审计留档）

### 8.2 Tab 2：借用归还流水
```
借：点右上角「➕ 新增借用」
    → 借用人类型：内部员工（选花名册）/ 外部客户 + 手机号
    → 批量扫条码 / 搜索勾选
    → 借期：借出日期 + 预计归还（超过 7 天自动黄色预警，>15 天红色）
    → 押金（可选）：例蟒袍 1 件押 500 元
还：列表点「归还」→ 实际归还日期 + 完好检查
    → 有损坏：扣押金 + 写 damageFee + 同步 fin_ledger（其他收入/损坏赔偿）
```

### 8.3 Tab 3：盘点
```
1. 新建盘点单：名称（如「8/3 服装仓月末盘点」）+ 类别范围（服装全选 / 灯光音响）
2. 账面库存自动快照（盘点前的系统库存，锁定）
3. 手机扫码盘点（或人工录入实盘数量） → 每扫 1 行实时比对
4. 结束 → 自动算：差异率 %（≤ 1% 自动通过；>1% 财务总监复审）
5. 需调整 → 自动生成库存调整凭证（fin_ledger_v1 一条）
6. 复核人（≠ 盘点人）→ 签字通过
```

## 九、财务收支台账（finance.html · 6 Tab · 🔴 重点！）

### 9.1 标准财务流程（月底关账 5 步）
```
Step 1 → Tab 2（收款登记）：当月所有订单收款已登记（与银行流水逐笔对）
Step 2 → Tab 1（收支流水）：当月所有凭证 draft → reviewed → reconciled
Step 3 → Tab 4（未收欠款）：列表检查，>30 天未收 → 团长催款
Step 4 → Tab 5（发票）：开票记录全部关联流水，无漏票
Step 5 → Tab 6（月度对账）：导入银行流水 CSV → 自动核销 → 差异 0 → 关账
→ 关账后当月所有凭证锁定（只可作废红冲，不可修改）
```

### 9.2 Tab 1：收支流水（核心凭证入口）
- ✅ **所有财务操作的唯一凭证入口**：禁止绕路直接写库，必须走顶部「➕ 新增凭证」
- 10 类来源：演出收款 / 工资发放 / 道具采购 / 库存盘点调整 / 差旅报销 / 场租水电 / 社保缴纳 / 税费 / 其他收入 / 其他支出
- 行操作：
  - 审核：制单人 caiwu / 审核人 admin（必须 2 个人不同，caiwu 不能自己审自己）
  - 作废（红冲）：不能物理删除，写负数凭证 + 关联原凭证号，备注写原因
  - 导出：勾选若干 → 导出 Excel（月末关账存档）

### 9.3 Tab 2：订单收款（财务登记入口）
和 orders.html 的「登记收款」同入口，两边双向同步。

### 9.4 Tab 3：工资发放（来自考勤推送）
来自 attendance.html 「推送财务」按钮，这里可以：
- 筛选月份 → 批量标记：已发放/银行处理中/发放失败
- 发放失败（银行卡号错/余额不足）→ 手动处理 + 重发

### 9.5 Tab 4：未收欠款（重点，之前的空白页已修复）
```
修复后的空态面板（订单全清时显示）：
  📭 大图标 + 橙色虚线框
  标题：「暂无未收欠款，剧团财务健康 ✅」
  三步卡：①录入演出订单 → ②按计划登记收款 → ③出现未收才会显示在这里
  3 按钮：
   · ↺ 清空筛选（恢复客户/剧目/月份/状态默认）
   · 💳 返回收支流水 Tab
   · 📋 去订单预约管理（跳 booking.html/orders.html）

有欠款时显示：
  顶部筛选区：客户 / 剧目 / 月份 / 状态（未付清/部分）+ 重置 + 查询
  表格 13 列：订单号 / 客户 / 剧目 / 合同额 / 已收 / 未收 / 逾期天数 / 联系电话 / 上次收款日 / 负责人 / 备注
  行操作：📞 催（复制催款短信模板） / 💰 登记收款（直接弹收款登记框） / 📄 催款函 PDF 打印
  右下角分页器 + 汇总行：未收合计 ¥ XXX,XXX
  纵向滚动 ≤ 4 屏（不会十几屏滚不到底）✅
```

### 9.6 Tab 5：发票管理
- 新增发票 → 选流水凭证号 → 填发票代码 / 号码 / 金额 / 购方抬头 / 购方税号
- 红冲 → 关联原发票 → 生成负数发票 → 财务备注原因
- 作废 → 原发票号码保留 + 状态作废（永不删除）

### 9.7 Tab 6：月度对账（银行 vs 账面）
```
1. 选对账月份 + 选账户（建行对公/工行对公/微信/支付宝）
2. 下载银行流水 CSV（对应银行网银导出格式）→ 点上传
3. 系统自动核销（金额+日期±3天 匹配 → 自动打勾）
4. 未核销的 → 手动点「匹配 → 选对应账面凭证」
5. 全部核销完 → 差异 0 → 对账通过 → 生成月度对账报告（A4 打印，财务归档）
6. 关账 → 当月数据全部锁定（admin 特殊权限可解）
```

### 14.2 Tab 2：数据备份 & 恢复
```
备份步骤：

2. 系统备份所有表 → 生成 gzip base64 大对象 → 写 backups_v2 + 浏览器自动下载一份 ZIP 本地
3. 下载后的 ZIP 一定要存到剧团独立的 U 盘 / 云盘（2 份异地）

恢复步骤（慎用，会覆盖当前所有数据！）：
1. 先立刻备份当前状态（操作第 1 步）
2. 选择历史备份点 → 点「恢复」→ 弹出 3 次确认框 + 输入 admin 账号密码 2 次
3. 恢复完成自动刷新 → 登录 → 冒烟测试 14 页
```

## 十五、常见问题 FAQ（按频率）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| **1** | 登录提示「🔐 生产模式：请先配置后端鉴权地址」 | 默认生产模式，未切 demo / 未接后端 | ① 本地验收：F12 执行 `localStorage.setItem("qaxqjt_deploy_mode","demo")` 刷新 <br> ② 生产：按 E-2 文档配置 `__BACKEND_AUTH_URL` |
| **2** | 切到「⏳ 未收欠款」显示空白橙色面板？ | **不是 Bug**，是所有订单都结清了 | 面板上有「📋 去订单预约管理」新增订单 → 故意不付清 → 回来就看到列表了 |
| **3** | 未收欠款 Tab 连续滚十几屏不到底 | 旧版本 Bug，8.3 版已修 | 请升级到 V2026.8.3 最终版 ZIP，现在 scrollHeight / clientHeight = 3.74，≤ 4 屏 |
| **4** | 上传考勤 CSV 提示「未找到姓名列」 | CSV 列名没写「姓名」或写成了「名字/员工姓名」 | 下载示例 CSV，严格按示例列名填（模糊匹配支持：员工名、员工姓名、Name） |
| **5** | 员工迟到 20 分钟但系统没扣款？ | wage_rules_v1 规则里 0-15=0，16-30=30，20 分钟应该扣 30 元，请检查：① 该员工对应的 wage_rule 是否正确绑定；② 考勤类型是否真的是"迟到"（不是"事假"） |
| **6** | 财务「推送工资」后 fin_ledger 里没看到凭证？ | 检查 3 项：① 当前用户是不是 admin/caiwu 有权限？② 工资表是不是已经批准了（draft 不能推）？③ 当月是不是已关账（关账后禁止新凭证）？ |
| **7** | 库存盘点差异 1.2% 不让通过？ | 默认容差 1% 自动通过，>1% 必须走 admin 财务总监复审 → system.html 给账号加「inventory:stocktake_override」权限 → 再点通过 |
| **8** | cast-sheet 打印 A4 阵容卡时空白？ | PDF 生成前未选要打印的场次 → 顶部多场管理 Tab → 勾 2-3 场前面的勾选框 → 再点「🖨 勾选打印」 |
| **9** | 民营组团套用模板后 36 人没填满？ | 模板定义默认人数 36，但实际模板里某行当选了"可缺人 1-2 名" → 正常现象，补齐需要的人即可，不会预算报错 |
| **10** | 手机微信里上传 PDF/扫描件失败？ | 微信 X5 内核偶发 FormData 文件 > 8MB 拦截 | ① 图片先压缩（微信拍照 2-3MB 可过）<br>② 换手机浏览器 Edge/Chrome 独立打开<br>③ 后端对接后调整 `maxUploadSize = 20MB` |
| **11** | 忘记密码 + 短信也收不到？ | 联系 admin 超级管理员 → accounts.html → 找到对应账号 → 点「重置密码」→ 系统生成 12 位新密码 + 强制 7 天内改密 |
| **12** | 月末关账后发现 1 张凭证错了？ | 关账后不能改原凭证 → 走「红冲」流程：fin_ledger 里作废原凭证 + 新增一张正确凭证 + 备注写清楚「红冲 202608XX 号凭证，原因：XXX」+ 财务审核人签字 |
| **13** | 备份 ZIP 下载失败（显示「超出 localStorage 配额」） | 浏览器 localStorage 通常 5-10MB，数据超量 | ① 清理旧备份：backups_v2 删 90 天前备份 + 清浏览器缓存<br>② 后端对接后备份直接存 COS，不走 localStorage |
| **14** | 浏览器刷新/换电脑后登录态消失？ | 正常安全机制：Session 2 小时 TTL，跨电脑必须重新登录 | 勾选「记住用户名」≠ 记住登录态，仅记住用户名，密码仍需输 |
