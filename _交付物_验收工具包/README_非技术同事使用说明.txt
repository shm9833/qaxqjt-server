【你只需要做这 3 步】

第 1 步 · 确认安装过 Node.js（一次即可，以后不用再装）
--------------------------------------------------------
  打开"命令提示符"（Windows 键 + R，输入 cmd 回车），输入：
      node -v
  如果显示类似 "v20.12.0" 这类字母+数字 → 已安装，跳到第 2 步。
  如果显示 "不是内部或外部命令" → 浏览器打开 https://nodejs.org/zh-cn
      → 下载"推荐版"LTS → 安装时一路下一步（默认全勾即可）。

第 2 步 · Windows 用户：直接双击运行
--------------------------------------------------------
  在本文件夹里，找到：
      一键验收.bat
  用鼠标左键双击它（或右键 → 打开）。
  首次运行会自动安装"jsdom"组件（只装这一次，1分钟内），之后自动开始测试。

  macOS / Linux 用户：
      打开终端，cd 进入本文件夹，执行：
      chmod +x ./一键验收.sh  &&  ./一键验收.sh

第 3 步 · 看完结果后做两件事
--------------------------------------------------------
  A. 如果最后一行写着"✅ 三项任务全部验收通过..."
     → 直接截图最后 10 行（或截图整个窗口）发给技术对接人即可。
  B. 如果最后一行写着"❌ 验收未完全通过..."
     → 找到本文件夹里刚生成的： 验收报告_YYYYMMDD_HHMMSS.log
        把这个 .log 文件直接发给技术对接人即可。

【常见问题 FAQ】

Q: 双击一闪而过没看到内容？
A: 右键 "一键验收.bat" → 编辑，看最后一行是不是有 "pause"；
   或者直接打开 cmd，把 .bat 文件拖进去回车，就能看到错误。

Q: 提示 "未检测到 Node.js"？
A: 回到第 1 步安装 Node.js。

Q: 测试要跑多久？
A: 一般 30~60 秒。最高并发阶段（200 虚拟用户）会稍微卡住几秒，正常现象。

Q: 需要联网吗？
A: 只在"首次运行自动安装 jsdom"时需要联网。如果已经安装过 jsdom，全程离线可跑。
   （验收对象是本地 HTML 页面，不访问任何远程服务器）
